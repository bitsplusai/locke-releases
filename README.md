  Requirements

  - Ollama — Locke will install it for you on first launch, or download it from https://ollama.com
  - 8 GB RAM minimum (16 GB recommended)
  - ~10 GB free disk space for AI models and vector database
  - Windows 10+, macOS 12+, or Linux (64-bit)

  Features

  - Chat with your documents using local AI models — PDF, DOCX, XLSX, PPTX, CSV, HTML, images, and 43 file types
  - Optional vision model for extracting text from images and photos
  - Semantic search with source citations — click a source to preview the original file
  - 100% private — no cloud, no telemetry, no accounts, no data ever leaves your machine
  - Multiple AI models — Llama 3.1, Mistral, Gemma, and more via Ollama
  - 4 color themes — Cyan, Violet, Rose, Amber
  - Cross-platform — Windows, macOS, Linux

  Getting Started

  1. Download and install Locke
  2. Launch the app — the setup wizard will guide you through installing Ollama and downloading an AI model
  3. Add a folder containing your documents
  4. Start chatting with your documents

  Privacy

  - All documents are processed and stored locally on your machine
  - AI inference runs locally through Ollama
  - No telemetry, analytics, or tracking
  - The only external network call is downloading Ollama (one-time, user-initiated)
